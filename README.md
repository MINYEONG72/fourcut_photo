# 삼성네컷 — GitHub Pages 버전

## 업로드
압축을 풀어 `index.html`, `style.css`, `app.js`, `frames/` 폴더를 GitHub 저장소 **최상위**에 올립니다. ZIP 자체는 올리지 마세요. GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## 기능
- 포토부스 스타일 UI / 원본 3개 프레임
- 프레임 속 실시간 웹캠 미리보기
- 10초 간격 8컷 촬영 및 찰칵 효과음
- 4컷 선택 후 정확한 사진 슬롯에 합성
- 산타 프레임은 사진 2칸과 얼굴 구멍 2칸으로 구성. 산타 모자·수염은 유지
- 산타 얼굴 높이 조절 슬라이더
- PNG 저장 / 지원 브라우저에서 공유

## 주의
웹캠은 HTTPS(GitHub Pages) 또는 localhost에서 사용해야 합니다. 사진은 브라우저 안에서 처리되며 서버로 전송되지 않습니다. 이메일 자동 발송은 별도 서비스가 필요합니다. 인물 얼굴 위치는 촬영 구도에 따라 다르므로 산타 얼굴 슬라이더로 조절하세요.
