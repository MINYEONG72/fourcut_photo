# 삼성네컷 — 2가지 프레임 버전

GitHub Pages에서 실행하는 정적 웹앱입니다.

## GitHub 업로드
- 저장소 최상단에 `index.html`, `style.css`, `app.js`를 업로드/교체합니다.
- `frames/` 폴더 안에 `red.jpg`, `cream.png`, `red-overlay.png`, `cream-overlay.png`를 넣습니다.
- GitHub Settings → Pages → Deploy from a branch → main / (root).
- 배포 후 Ctrl+Shift+R로 새로고침합니다.

촬영은 10초 간격으로 8장, 4장 선택, PNG 저장 및 공유 기능을 제공합니다. 카메라 사용을 위해 HTTPS 접속이 필요합니다.
